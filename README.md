# 🚀 BlogVerse Frontend

This repository serves as the official frontend application for the **BlogVerse REST API**. It is a modern, high-performance web application built with React and Vite.

---

## 🔗 Backend Repository

- 📦 **Backend GitHub Repository**: [https://github.com/acsuthar2006-ctrl/blogverse](https://github.com/acsuthar2006-ctrl/blogverse)
- 🖥️ **Local Backend Server**: `http://localhost:8080/api/v1`

---

## 📌 Project Overview

**BlogVerse** is a modern blogging platform. The frontend supports:
- JWT authentication and user sessions
- Reading, creating, and deleting posts
- A dual-strategy comment system
- Responsive design with a custom glassmorphism CSS theme

---

## 🛠️ Technology Stack

| Technology | Purpose |
| :--- | :--- |
| **React 18** | UI Library for building component-driven interfaces |
| **Vite** | Lightning-fast build tool and development server |
| **Vanilla CSS** | Scoped styling, glassmorphism design system, dark mode |
| **Lucide React** | Clean, responsive SVG icon set |
| **Axios** | HTTP client for API communication |
| **React Router** | Client-side routing |
| **React Hot Toast** | Toast notifications |

---

## 🚀 Getting Started

### 1. Clone & Setup

```bash
# Clone the repository
git clone https://github.com/acsuthar2006-ctrl/blogverse-frontend.git
cd blogverse-frontend

# Install dependencies
npm install

# Start local development server
npm run dev
```

The app will be available at `http://localhost:5173`. Make sure the Spring Boot backend is running on `http://localhost:8080`.
